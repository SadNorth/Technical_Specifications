# Technical_Specifications

В данном ТЗ я написал достаточно простое 
приложение, Которое при отправке на него запроса GET возвращает JSON-ответ с описанием состояния приложения, а также его версией. 
Для написания данного приложения был выбран язык программирования Go в связи с тем, что лично мне он удобен, а также очень хорошо подходит для данной задачи. В роли хостинга выступил Vercel. Достаточно удобный инструмент для глобального доступа к проекту. У него широкий выбор настроек безопасности. Это и повлияло на мой выбор. Также для мониторинга состояния был выбран Uptime Robot.
Пайплайн ориентирован на запуск тестов. Основной тест был прописан в отдельном Go-файле - health_test.go. В нём мы взяли httptest, который позволяет протестировать HTTP handler без запуска HTTP-сервера. Затем запускается go vet, который ориентирован на проверку наличия в коде подозрительных конструкций и потенциальных ошибок.
Также перед проведением тестов runner устанавливает Go 1.27.0. Это версия на которой было написано приложение.
После проведения тестов происходит build приложения. Runner работает на ubuntu-latest.
После процесса проверки кода, runner переходит ко второму job, который ориентирован на deploy. Он также запускается на ubuntu и устанавливает Node.js, который требуется для работы Vercel CLI. Затем использует секреты, которые мы отдельно прописываем в GitHub Actions Secrets для доступа к deployment в Vercel (это VERCEL_TOKEN, VERCEL_ORG_ID и VERCEL_PROJECT_ID). Затем уже производится непосредственный деплой.
Для мониторинга состояния был развёрнут UptimeRobot, в котором установил обычный HTTPS-монитор.
Также я прописал .gitignore, чтобы лишние файлы не попали в сам публичный репозиторий.
